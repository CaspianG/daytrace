DAYTRACE FOR macOS — READ BEFORE INSTALLING
DAYTRACE ДЛЯ macOS — ПРОЧИТАЙТЕ ПЕРЕД УСТАНОВКОЙ

ENGLISH

Daytrace is currently distributed without an Apple Developer ID signature and
without Apple notarization. macOS may therefore say that Apple could not verify
the app is free of malware. This is a Gatekeeper trust warning caused by the
missing paid Apple certificate; it is not a malware detection result.

1. Compare the downloaded DMG's SHA-256 with SHA256SUMS.txt on the same GitHub
   Release page.
2. Open the DMG and drag Daytrace to Applications. During an update choose
   Replace, not Keep Both; keep exactly one /Applications/Daytrace.app copy.
3. In Finder > Applications, Control-click (or right-click) Daytrace and choose
   Open, then choose Open again.
4. If it is still blocked, open System Settings > Privacy & Security, scroll to
   Security, find the message about Daytrace, and click Open Anyway. Confirm
   with your password or Touch ID if macOS asks.
5. Launch Daytrace and grant Accessibility access when its own setup explains
   the permission. This second permission is required for local activity
   tracking and is separate from Gatekeeper.

From v0.5.4 onward, the in-app Update button verifies the DMG, replaces the
installed app, repairs a numbered copy such as Daytrace 2.app, and relaunches
Daytrace automatically. Updating from v0.5.3 or older requires this manual DMG
replacement once because the old installed binary does not contain the new
updater. An unsigned update can still make macOS request Accessibility again;
Daytrace can open the correct settings page but cannot grant itself access.

Do not disable Gatekeeper globally. Download Daytrace only from the official
GitHub repository: https://github.com/CaspianG/daytrace/releases/latest

Full guide: https://github.com/CaspianG/daytrace/blob/main/docs/MACOS_INSTALL.md

РУССКИЙ

Сейчас Daytrace распространяется без подписи Apple Developer ID и без
нотарификации Apple. Поэтому macOS может написать, что Apple не удалось
проверить приложение на отсутствие вредоносного ПО. Это предупреждение доверия
Gatekeeper из-за отсутствия платного сертификата Apple, а не результат
обнаружения вируса.

1. Сверьте SHA-256 скачанного DMG с файлом SHA256SUMS.txt в том же GitHub Release.
2. Откройте DMG и перетащите Daytrace в «Программы». При обновлении выберите
   «Заменить», а не «Сохранить обе»; оставьте одну /Applications/Daytrace.app.
3. В Finder > «Программы» нажмите Daytrace с удержанием Control (или правой
   кнопкой), выберите «Открыть», затем ещё раз «Открыть».
4. Если запуск всё ещё заблокирован, откройте «Системные настройки» >
   «Конфиденциальность и безопасность», прокрутите до раздела «Безопасность»,
   найдите сообщение о Daytrace и нажмите «Всё равно открыть». Подтвердите
   действие паролем или Touch ID, если macOS попросит.
5. Запустите Daytrace и выдайте «Универсальный доступ», когда приложение объяснит
   разрешение. Оно нужно для локального сбора активности и не связано с
   предупреждением Gatekeeper.

Начиная с v0.5.4 кнопка обновления сама проверяет DMG, заменяет установленное
приложение, исправляет номерную копию вроде Daytrace 2.app и перезапускает
Daytrace. При переходе с v0.5.3 или старше ручную замену через DMG нужно сделать
один раз: в старом установленном файле нового механизма ещё нет. После обновления
без подписи macOS всё ещё может повторно запросить «Универсальный доступ»;
Daytrace откроет нужный раздел, но не может выдать разрешение самому себе.

Не отключайте Gatekeeper целиком. Скачивайте Daytrace только из официального
репозитория: https://github.com/CaspianG/daytrace/releases/latest

Полная инструкция: https://github.com/CaspianG/daytrace/blob/main/docs/MACOS_INSTALL_RU.md
