# Установка Daytrace на macOS без нотарификации Apple

Daytrace работает на macOS 12 и новее, на Mac с Apple Silicon и Intel. Текущая универсальная сборка распространяется без подписи Apple Developer ID и без нотарификации Apple, потому что у проекта пока нет этих учётных данных Apple.

Поэтому Gatekeeper может показать сообщение **«Apple не удалось проверить Daytrace на наличие вредоносного ПО»** или **«Невозможно открыть Daytrace, так как не удаётся проверить разработчика»**. Это предупреждение о доверии из-за отсутствия подписи Apple. Оно не означает, что macOS обнаружила вирус.

## Перед открытием файла

1. Скачайте DMG только с [официальной страницы релизов Daytrace](https://github.com/CaspianG/daytrace/releases/latest).
2. Скачайте `SHA256SUMS.txt` из того же релиза.
3. Откройте Terminal, выполните `shasum -a 256 ~/Downloads/Daytrace-*-macOS-universal.dmg` и сравните результат со строкой DMG в `SHA256SUMS.txt`.

Хеш должен совпасть полностью. Если он отличается, удалите скачанный файл.

## Установка и первый запуск

1. Откройте `Daytrace-…-macOS-universal.dmg`.
2. Перетащите **Daytrace** в **«Программы»**.
3. Откройте Finder и выберите **«Программы»**.
4. Нажмите **Daytrace** с удержанием Control или правой кнопкой мыши и выберите **«Открыть»**.
5. В окне подтверждения ещё раз нажмите **«Открыть»**.

Если macOS всё равно блокирует запуск:

1. Один раз попробуйте открыть Daytrace, чтобы macOS сохранила запись о блокировке.
2. Откройте **«Системные настройки» → «Конфиденциальность и безопасность»**.
3. Прокрутите до раздела **«Безопасность»** и найдите сообщение о блокировке Daytrace.
4. Нажмите **«Всё равно открыть»**, подтвердите действие паролем или Touch ID, если потребуется, затем нажмите **«Открыть»**.

Обычно это исключение требуется только при первом запуске конкретной скачанной сборки. Не отключайте Gatekeeper целиком и не вставляйте из интернета случайные команды для удаления quarantine-атрибутов.

## Включение локального сбора активности

После запуска самого приложения Daytrace покажет отдельную настройку «Универсального доступа». Разрешение нужно нативному локальному сборщику, чтобы видеть активное приложение и метаданные видимого активного окна. Оно не открывает облачный доступ и не связано с предупреждением Gatekeeper.

Нажмите **«Открыть настройки доступа»**, включите Daytrace в разделе **«Системные настройки» → «Конфиденциальность и безопасность» → «Универсальный доступ»** и вернитесь в приложение. Сбор запустится автоматически. Можно продолжить без разрешения, но таймлайн останется пустым, пока доступ не выдан.

## Почему предупреждение нельзя убрать программной настройкой

Для программ вне App Store Apple убирает такое предупреждение только после подписи платным сертификатом **Developer ID Application** и успешной проверки в сервисе нотарификации Apple. Самоподписанный или ad-hoc сертификат не создаёт такого доверия. В проекте сохранён строгий сценарий подписанного релиза на будущее, но текущие публичные macOS-артефакты честно обозначены как неподписанные и содержат эту инструкцию.

Технические детали для сопровождающего проекта: [подпись и нотарификация macOS](MACOS_SIGNING.md).
